# Wkład w projekt "Generator Kolorowanek AI"

Dziękujemy za zainteresowanie rozwojem tego projektu!

## Jak zgłaszać błędy lub propozycje
- Otwórz issue na GitHubie i opisz problem lub pomysł.
- Dołącz zrzuty ekranu lub przykłady, jeśli to możliwe.

## Jak zgłaszać pull requesty
1. Sklonuj repozytorium i utwórz nową gałąź (`git checkout -b twoja-funkcja`).
2. Wprowadź zmiany i przetestuj je lokalnie.
3. Upewnij się, że aplikacja działa i nie generuje błędów.
4. Opisz krótko zmiany w pull requeście.

## Styl kodowania
- Stosuj PEP8 (Python).
- Komentuj nietypowe fragmenty kodu.
- Staraj się zachować przejrzystość i prostotę.

## Kontakt
Masz pytania? Napisz na GitHubie lub skontaktuj się przez profil autora.
