# Projekt: Kolorowanki

## Opis

Aplikacja do kolorowania obrazków.

## Funkcjonalności

- [ ] Wybór obrazka do pokolorowania
- [ ] Paleta kolorów
- [ ] Narzędzie do wypełniania kolorem
- [ ] Zapisywanie pokolorowanego obrazka

## Technologie

- HTML
- CSS
- JavaScript

## Instalacja

1.  Sklonuj repozytorium: `git clone https://github.com/AlanSteinbarth/Kolorowanki.git`
2.  Otwórz plik `index.html` w przeglądarce.

## Użycie

Wybierz kolor z palety i kliknij na obszar obrazka, który chcesz pokolorować.
